[ 3 Strengths ]
Niche terdefinisiKemeja casual, flannel, work shirt = buyer spesifik, bisa charge premium vs seller "semua jenis baju".
Overhead sangat rendahRp50rb transport + no sewa = struktur biaya paling lean di kategori ini.
Dual-channel presenceShopee + GitHub Pages catalog = dua titik tempur yang kebanyakan seller tidak miliki.
[ 3 Weaknesses ]
Margin 15–20% terlalu tipisSetelah Shopee fee (~6.5%) + packaging, net bisa di bawah 10%. Bisnis sampingan tidak bisa kompensasi dengan volume.
Buying strategy belum selektifRange Rp50–130rb tanpa kriteria ketat = hasil tidak konsisten dan berisiko rugi di item modal tinggi.
Tidak ada social proof115 followers, tanpa konten aktif = tidak ada pull organik. Shopee rewards toko dengan kecepatan transaksi.
[ 3 Opportunities ]
Kemeja kerja preloved = underserved nicheMayoritas seller fokus streetwear / womenswear. Pain point pekerja kantoran muda yang harus tampil rapi tapi budget terbatas.
Market tailwind 22.8% CAGRStigma "baju bekas" sudah sangat berkurang. Buyer online makin terbiasa beli preloved — lo masuk di momentum yang tepat.
Batch content, bukan live1 sesi foto weekend = 8–10 konten Instagram/TikTok. Kemeja mudah di-style. Awareness channel tanpa menyita waktu weekday.
